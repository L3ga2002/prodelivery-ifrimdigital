## Reviewer defects and fixes

1. P2: default patch serialization invented null values for omitted fields.
   Wrap serialization now preserves field presence and deliberate null clearing,
   retaining native include/exclude behavior and strict input validation.
2. P2: positive/negative zero generated different fingerprints for equal intent.
   Only digest payload float zeros are normalized recursively. Nonzero values
   are not rounded or changed; legacy monetary calculations remain unchanged.
